# CertLang - Mathematical Certificate Verification Language

CertLang is a domain-specific language designed for expressing and verifying mathematical certificates, particularly for computational proofs involving numeric bounds and inequalities.

## Directory Structure

- `spec/` - Language specification and grammar
- `interpreter/` - Simple interpreter implementation
- `examples/` - Example scripts and demonstrations
- `docs/` - Comprehensive documentation and book
- `tests/` - Test cases and validation scripts

## Quick Start

See `examples/collatz_cert.cl` for a simple example of verifying the Collatz stopping-time certificate.

For full documentation, see `docs/certlang_book.md`.
